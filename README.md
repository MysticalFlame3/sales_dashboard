# Sales Insight Dashboard

A **pixel-perfect, responsive sales analytics dashboard** built from a high-fidelity UI design.  
The project focuses on **exact visual accuracy**, modern frontend practices, and clean component architecture.

---

## 🔍 Overview

This dashboard visualizes sales performance, platform contributions, and user metrics in a clean, modern interface.  
It was built by carefully translating a design into code with attention to:

- Spacing
- Shadows
- Typography
- Colors
- Layout consistency
- Responsiveness

The goal was to match the design **as close as possible to the original (pixel-perfect)**.

---

## ✨ Features

- Pixel-perfect UI implementation from design
- Fully responsive layout (desktop, tablet, mobile)
- Modular and reusable React components
- Smooth charts and visual indicators
- Clean typography and spacing system
- Modern UI shadows and elevation system
- Accessible and readable UI elements

---

## 🛠 Tech Stack

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **PostCSS**
- **Lucide Icons**
- **CSS Variables for design tokens**
